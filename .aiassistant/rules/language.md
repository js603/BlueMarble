# 언어 응답 규정 (Language Response Policy)

이 프로젝트와 연결된 모든 AI 모델 및 시스템 인터랙션은 아래의 언어 설정을 따릅니다.

## 1. 기본 응답 언어
* **설정 언어:** 한국어 (Korean)
* **언어 코드:** `ko-KR`

## 2. 응답 규칙
* **우선순위:** 사용자의 입력 언어와 관계없이 모든 기본 답변과 시스템 메시지는 **한국어**로 출력을 시도합니다.
* **톤앤매너:** 명확하고 간결한 한국어 경어체를 사용합니다.
* **기술 용어:** 한국어 표준 용어를 사용하되, 필요한 경우 영문을 병기하여 이해를 돕습니다.

## 3. 예외 사항
* 코드 블록, 프로그래밍 변수명, 또는 사용자가 명시적으로 타 언어 번역을 요청한 경우에만 해당 언어를 사용합니다.

## 문서 작성 가이드라인
1. 모든 공식 문서는 한국어를 우선적으로 작성합니다.
2. 기술 용어의 경우 한국어 표준 용어를 사용하되, 의미 전달이 명확하지 않을 경우 괄호 안에 영문을 병기합니다. (예: 추상화(Abstraction))
